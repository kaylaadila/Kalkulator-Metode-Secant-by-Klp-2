## Deskripsi

Kalkulator Metode Secant merupakan proyek pengembangan aplikasi
untuk menyelesaikan persamaan nonlinier dengan menggunakan
metode Secant.

Aplikasi ini dirancang untuk membantu pengguna memahami proses
pencarian akar persamaan melalui perhitungan iteratif yang
disajikan dalam bentuk tabel dan visualisasi grafik.

## Tujuan

1. Mengimplementasikan algoritma metode Secant.
2. Menampilkan proses perhitungan pada setiap iterasi.
3. Menentukan pendekatan akar persamaan nonlinier.
4. Memvisualisasikan fungsi dan akar persamaan dalam bentuk grafik.
5. Membantu proses pembelajaran metode Secant pada mata kuliah
   Komputasi Numerik.

## Fitur

- Input fungsi persamaan.
- Input dua tebakan awal.
- Pengaturan toleransi error.
- Perhitungan iterasi metode Secant.
- Tabel hasil perhitungan setiap iterasi.
- Informasi hasil pendekatan akar.
- Visualisasi grafik fungsi dan akar persamaan.
